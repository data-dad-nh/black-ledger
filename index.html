The shape of a script


Python reads your indentation. Lines that belong under a header must be indented four spaces (press Tab). A header such as for or if must end with a colon.


Loops: do it for each item


A list holds many things. A for loop runs its indented lines once per item, and the name you pick stands for the current item.


for lamp in street.lamps():
    lamp.dim(percent=50)


Read it as: for each lamp in the street's lamps, dim it.


Conditions: only when true


An if runs its indented lines only when its test is True. Tests are often a True or False property.


for door in building.doors():
    if door.locked:
        door.report()


Here only locked doors get reported. Open ones are skipped.

Reading errors


SyntaxError means the code is not valid Python, often a missing colon. NameError means you used a name that does not exist or never wrote the line the system expects. Each failed run adds trace, so read the message before you try again.
